# BERT, pen and paper

Two fully worked numerical examples of BERT's pre-training tasks. Both use the **same tiny BERT** (hidden size 4, 2 heads, feed-forward size 8, one encoder layer, 8-token vocabulary): the embeddings and the encoder layer are identical, and only the head on top differs, just as in real BERT.

| Example | Input | What it shows |
|:--|:--|:--|
| [**MLM.md**](MLM.md): masked language modelling | `[CLS] socrates [MASK] plato [SEP]` | 80/10/10 masking, token + segment + position embeddings, embedding LayerNorm, bidirectional multi-head self-attention, Add & Norm, GELU feed-forward, the MLM head (dense + GELU + LayerNorm + tied output matrix), softmax over the vocabulary, loss and gradient |
| [**NSP.md**](NSP.md): next sentence prediction | `[CLS] socrates taught plato [SEP] plato wrote [SEP]` | sentence-pair packing, segment embeddings A/B, the same encoder steps, attention across the sentence boundary, pooler (dense + tanh) on `[CLS]`, IsNext/NotNext classifier, loss and gradient |

Every number in both documents is generated by [`bert_pen_and_paper.py`](bert_pen_and_paper.py). Intermediate results are rounded to 4 decimals, and the rounded values are used in the next step, so you can check everything with a calculator:

```bash
python3 bert_pen_and_paper.py          # regenerate MLM.md and NSP.md
python3 bert_pen_and_paper.py --check  # compare with a full-precision run
```

For the full encoder–decoder Transformer, see [`../transformer-pen-and-paper/`](../transformer-pen-and-paper/).
